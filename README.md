# Web Application Security Labs

This repository contains my personal notes and learning progress from hands-on web application security labs.

## Learning Platform
- PortSwigger Web Security Academy

## Topics Practiced
- SQL Injection (SQLi)
- Cross-Site Scripting (XSS)
- Access Control and IDOR
- Server-Side Request Forgery (SSRF)
- File Upload Vulnerabilities
- Path Traversal
- Authentication and Cross-Site Request Forgery (CSRF)
- Race Conditions

## Learning Objectives
- Understand how common web vulnerabilities work.
- Practice testing application inputs in controlled lab environments.
- Improve vulnerability identification and analysis skills.
- Learn about security implications and remediation approaches.

## Scope
All practice is conducted in authorized training labs and controlled environments.

Computer Science graduate interested in Penetration Testing, Web Application Security, and Vulnerability Assessment.

I am continuously improving my practical skills through hands-on labs and structured learning.
