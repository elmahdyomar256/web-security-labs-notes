# SQL Injection — Learning Notes

## Overview
SQL Injection (SQLi) is a web application vulnerability that can occur when user input is handled unsafely in database queries.

## Hands-on Practice
- Practiced SQL Injection labs on PortSwigger Web Security Academy.
- Studied how application inputs can affect database query behavior.
- Practiced identifying SQL Injection vulnerabilities in controlled lab environments.

## Key Takeaways
- Understand how SQL queries may be affected by user input.
- Practice testing inputs methodically.
- Learn how to document findings and understand potential security impact.
